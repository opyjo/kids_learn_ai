---
solution_code: |
  # My Math Story: The Birthday Party
  # Every print statement solves one part of the story.

  print("🎂 THE BIRTHDAY PARTY MATH STORY 🎂")

  # 1. Guests from two groups arrive.
  print("Guests:", 8 + 6)

  # 2. Some balloons pop.
  print("Balloons left:", 30 - 7)

  # 3. Each table gets four party hats.
  print("Party hats needed:", 5 * 4)

  # 4. Pizza slices are shared equally.
  print("Slices per guest:", 28 / 14)

  # 5. Two trays each hold twelve cupcakes.
  print("Cupcakes:", 2 * 12)

  # 6. The guests eat nine cupcakes.
  print("Cupcakes left:", 24 - 9)

  # 7. Three more friends arrive.
  print("New guest total:", 14 + 3)

  # 8. Forty stickers are shared among eight children.
  print("Stickers per child:", 40 / 8)

  print("🎉 The party maths is complete! 🎉")
---


## Walk through it

1. Read the story in order and let students call out which operator each situation needs.
2. Connect **joining** with `+`, **taking away** with `-`, **equal groups** with `*`, and **sharing equally** with `/`.
3. Ask students to predict a line before running it.
4. Notice that Python displays division answers as decimals such as `2.0`.

## Success checklist

- [x] Addition, subtraction, multiplication, and division
- [x] Eight different mathematical print statements
- [x] A comment explaining every calculation
- [x] One consistent story
- [x] Code that runs without errors

## Common mistakes

| Mistake | Review point |
|---|---|
| Using `x` for multiplication | Python multiplication uses `*`. |
| Using `÷` for division | Python division uses `/`. |
| Putting the calculation inside quotes | `"8 + 6"` prints text; `8 + 6` calculates the answer. |
| Writing one long list of unrelated sums | The calculations should connect to a readable story. |

## Ask the class

1. Why do the division answers end in `.0`?
2. Which line would change if two more guests arrived?
3. Can you invent a ninth calculation that fits this party?

## Another valid approach

Any theme is acceptable. Students can use direct calculations as shown here or store numbers and answers in variables first. Both approaches satisfy the assignment when all four operators and eight calculations are present.
