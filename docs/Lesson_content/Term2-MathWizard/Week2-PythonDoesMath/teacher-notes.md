# Term 2, Lesson 2: Python Does Math! 🧮

## Teacher's Guide

**Duration:** 60 minutes | **Week:** 2 of 9

## Purpose

Introduce the four arithmetic operators through one connected model rather than a sequence of unrelated `print()` exercises. Students build a Score Tracker, change its starting values, and discover that reusable formulas are more powerful than one-off answers.

## Objectives

Students can select `+`, `-`, `*`, or `/`, save results in variables, predict before running, test a model by changing its data, and label output clearly.

## Lesson Flow

| Time | Activity |
| --- | --- |
| 0–7 min | Operator story match-up |
| 7–17 min | Predict and trace one shared model |
| 17–27 min | Guided Score Tracker start |
| 27–43 min | Independent build and improvement |
| 43–52 min | Three planned tests |
| 52–57 min | Partner-selected test and feedback |
| 57–60 min | Exit ticket |

Limit teacher typing to one short model. Require students to predict each calculation before execution.

## Teaching Notes

- Keep inputs as variables. Interactive numeric input and conversion arrive in Lesson 4.
- Treat `/` producing `5.0` as an observation, not a full data-types lecture.
- Do not preview order of operations deeply; Lesson 3 owns that concept.
- Ask “What does this number mean?” whenever a student shows an unlabelled result.
- If students finish early, have them improve the model or design a test—not add rows of unrelated arithmetic.

## Differentiation

**Support:** Give operator cards and a planning table with formula-in-words. Let students build total and doubled score before difference and average.

**Extension:** Add a third score and update both total and average. Ask which existing formulas must change and why.

## Assessment

Collect evidence of four meaningful operations, result variables, predictions for three test pairs, and one revision after partner feedback.

## Homework Boundary

The Event Planner is a connected model using fixed variables. It must not introduce `input()` conversion or become a calculator project.

## Looking Ahead

Lesson 3 adds complete groups, leftovers, powers, and intentional calculation order.
