# Term 2, Lesson 1: Welcome Back — Term 1 Skills Relay! 🔁

## Teacher's Guide

**Duration:** 60 minutes | **Week:** 1 of 9

## Purpose

This is a diagnostic recap, not a lecture through every Term 1 topic. Students rotate through prediction, repair, transformation, building, and peer testing. Use their Skills Check to identify support needs before the math progression begins.

## Objectives

Students reactivate variables, strings versus numbers, f-strings, string methods, comments, and text `input()`. They build and improve a Term 2 Passport and identify one personal learning need.

## Lesson Flow

| Time | Activity |
| --- | --- |
| 0–5 min | Welcome and explain diagnostic purpose |
| 5–12 min | Station 1: predict text versus number |
| 12–20 min | Station 2: repair two bugs |
| 20–28 min | Station 3: string-method partner challenges |
| 28–44 min | Station 4: build Term 2 Passport |
| 44–52 min | Station 5: exchange and revise |
| 52–57 min | Skills Check |
| 57–60 min | Exit ticket and Lesson 2 preview |

## Facilitation Notes

- Gather predictions before anyone runs Station 1.
- At Station 2, ask students to reproduce and describe the symptom before repairing it.
- Keep `input()` to text answers. Numeric input conversion is the new learning in Lesson 4.
- Emphasize safe, minimal data collection.
- During the build, ask questions and release small hints instead of projecting a finished passport.
- Record students who struggle with variable naming, the missing `f`, or storing an input answer.

## Differentiation

**Support:** Pair with a confident peer, provide the starter unchanged, and require one question and one f-string before extensions.

**Extension:** Let students author a fair debugging case with one intentional Term 1 bug and an expected answer.

## Assessment

Use station explanations, the working passport, partner revision, Skills Check, and exit ticket. The lesson is successful when it reveals gaps honestly; do not turn the diagnostic into a high-stakes grade.

## Looking Ahead

Lesson 2 introduces arithmetic with fixed number variables. Lesson 4 later converts numeric `input()` with `int()`, so this recap should not pre-teach that solution.
