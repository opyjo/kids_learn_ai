# Teacher Notes — Week 4: Layouts for Every Screen

## Outcomes

Learners distinguish Flexbox from Grid, explain `fr`, and use a media query to preserve readability on a narrow screen.

## Suggested flow

- Start with three learners holding cards in a row. Narrow the available space and ask what should happen.
- Demonstrate Flexbox for the two-part hero and Grid for the repeated cards.
- Use browser width or responsive mode if available; the embedded preview also responds as the lesson pane changes width.
- Require a prediction before every layout edit.

## Differentiation

Ages 9–10 can edit marked values (`3`, `1fr`, `650px`) and explain the visual result. Ages 11–13 should attempt `auto-fit/minmax` and describe the browser's decision.

## Exit ticket

Ask: “Would you choose Flexbox or Grid for three repeated cards, and why?” Accept multiple defensible answers if the reasoning is clear.
