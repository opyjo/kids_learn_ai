# Teacher Notes — Week 6: Make the Page Respond

## Outcomes

Learners identify selection, event, and response; edit an `if/else`; and add one working choice without removing keyboard accessibility.

## Suggested flow

- Act out event-driven programming: one learner is the button, one the listener, one the message.
- Trace the code with a finger before clicking.
- Make changes in the order HTML choice → JavaScript decision → message.
- Have learners test with keyboard Enter as well as pointer click.

## Differentiation

Ages 9–10 may copy the existing button and `else if` pattern with colour-coded placeholders. Ages 11–13 can refactor repeated decisions into an object lookup, but only after the three-choice version works.

## Common errors

- `querySelectorAll` returns a collection, so it needs a loop.
- `dataset.minutes` begins as text; `Number(...)` converts it.
- A mismatched quote often causes the entire JavaScript file to stop.
