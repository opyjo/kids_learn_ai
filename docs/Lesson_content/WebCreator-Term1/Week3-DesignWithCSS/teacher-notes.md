# Teacher Notes — Week 3: Design with CSS

## Outcomes

Learners explain selector/property/value, distinguish padding from margin, reuse a class, and test colour choices for readability.

## Suggested flow

1. Open with two versions of the same HTML: readable and deliberately chaotic.
2. Live-edit only the `:root` variables to demonstrate a design system.
3. Use a physical box analogy: learner = content, personal space = padding, tape line = border, space between learners = margin.
4. Complete the core mission and conduct a partner readability check.

## Differentiation

For ages 9–10, limit initial editing to variables and marked declarations. For ages 11–13, require a modifier class and an explanation of why copied CSS becomes difficult to maintain.

## Watch for

- Missing semicolons usually affect one declaration; missing braces can affect much more.
- Learners may choose low-contrast neon colours because they look exciting. Ask them to read a full sentence rather than simply naming the colour.
