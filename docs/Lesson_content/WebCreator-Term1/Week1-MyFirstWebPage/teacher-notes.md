# Teacher Notes — Week 1: My First Web Page

## Outcomes

Learners can identify the jobs of HTML, CSS, and JavaScript; edit headings and paragraphs; and state at least three kinds of personal information that must stay off a website.

## 60–75 minute flow

1. **Hook (8 min):** Compare a plain text note with a structured webpage. Ask which parts are title, section, and paragraph.
2. **Model (10 min):** Change one `<h1>` and one `<p>`. Narrate opening tag, content, closing tag.
3. **Core mission (20 min):** Circulate and check that learners edit content rather than deleting the structure.
4. **Safety pause (8 min):** Sort example details into “safe to share” and “keep private.”
5. **Power-ups (15 min):** Younger learners add a list from a model; older learners add a semantic section and explain it.
6. **Showcase (8 min):** Invite learners to share the preview, not personal details.

## Common misconceptions

- CSS is not “better HTML”; it has a different job.
- The page title in `<title>` appears in the browser tab, while `<h1>` appears on the page.
- A missing `>` or closing tag can change everything below it.

## Check for understanding

Ask each learner: “If I want to change what the page says, which file do I begin with?” and “Name one detail that should never be placed on this page.”
