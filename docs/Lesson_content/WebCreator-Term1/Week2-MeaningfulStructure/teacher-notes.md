# Teacher Notes — Week 2: Build a Meaningful Page

## Outcomes

Learners use `header`, `main`, `section`, and `footer` appropriately; choose ordered or unordered lists; create an internal link; and distinguish a privacy check from a fact check.

## Suggested flow

- Display the starter page with CSS temporarily removed. Ask what still communicates structure.
- Build a human “webpage outline”: learners hold cards labelled `h1`, `h2`, `p`, `section`, and arrange them.
- Complete the core mission before introducing links.
- Run a two-column safety check: **Could identify me** / **Could be inaccurate**.

## Differentiation

Give ages 9–10 a printed tag bank and a partially completed list. Ask ages 11–13 to add a `nav` and test every destination. Do not require younger learners to memorize tags.

## Exit ticket

Show `<div class="title">` and `<h2>`. Ask which communicates meaning even when CSS is unavailable, and why.
