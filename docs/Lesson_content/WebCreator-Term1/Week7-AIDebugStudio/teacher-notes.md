# Teacher Notes — Week 7: AI Debug Studio

## Outcomes

Learners use a prediction-led debugging loop, provide minimal context to AI, evaluate a suggestion, and produce a small test report.

## Suggested flow

1. Demonstrate a bug and model weak debugging (“change everything”) versus evidence-led debugging.
2. Trace `currentIndex` through five clicks on paper.
3. Let pairs introduce controlled bugs from a teacher list: wrong selector, missing quote, misspelled variable, or incorrect comparison.
4. Use AI only after pairs record expected/actual behaviour.
5. Debrief one plausible but unnecessary AI suggestion.

## Safety boundary

Never paste API keys, account data, student names, or private project information into an AI system. The embedded project does not need any key.

## Assessment

The explanation is more important than speed. Ask: “What evidence showed where the bug was?” and “What did you reject from the AI answer?”
