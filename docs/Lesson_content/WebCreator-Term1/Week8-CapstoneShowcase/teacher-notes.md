# Teacher Notes — Week 8: AI for Good Capstone Showcase

## Outcomes

Learners finish a coherent private website, test it across accessibility and responsive criteria, and present evidence of their own decisions.

## Suggested flow

1. **Plan check (8 min):** Review audience, message, action, and privacy boundary.
2. **Build sprint (25 min):** Prioritize required elements before visual extras.
3. **Partner test (12 min):** Tester uses keyboard and narrow layout, then records one observation and one question.
4. **Revision (10 min):** Creator chooses which feedback to act on and explains why.
5. **Showcase (15+ min):** Two-minute demonstrations using the presentation prompts.

## Assessment rubric

- **Structure:** semantic HTML and logical headings
- **Design:** consistent and responsive CSS
- **Interaction:** understandable, working JavaScript
- **Inclusion:** keyboard, focus, contrast, and clear language
- **Responsibility:** privacy, fact-checking, and human oversight
- **Ownership:** learner can explain choices and debugging

Use “meeting / developing / extending” rather than ranking visual polish. A simpler project that the learner understands should score above a complicated project copied from AI.

## Publishing boundary

The in-app preview is intentionally private. Do not publish a learner project without the organization’s safeguarding process and explicit parent or guardian approval.
